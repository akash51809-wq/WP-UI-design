DEVELOPER CENTER

Build with the messaging API.

Clear request examples for the currently documented message and group endpoints.

01

Send Message

Send a WhatsApp message to one recipient.

POST
POST https://your-domain.com/api/message/send

Request Body

{
  "number": "+919876543210",
  "message": "Hello from API",
  "session": "main"
}

Response

{
  "success": true,
  "message": "Message sent"
}
02

Group Message

Send a message to a selected WhatsApp group.

POST
POST https://your-domain.com/api/group/message/send

Request Body

{
  "groupId": "120363012345678901",
  "message": "Hello group",
  "session": "main"
}

Response

{
  "success": true,
  "message": "Group message sent"
}
BASE URLReplace your-domain.com with the domain where your WhatsApp API is hosted.
