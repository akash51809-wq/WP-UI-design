FAQ
Common questions before you connect.
WhatsApp API किस काम आती है?
API आपके software को messaging workflows से connect करने का तरीका देती है, जिससे applications programmatically supported actions कर सकती हैं.
क्या bulk messaging available है?
हाँ, product workflow में bulk messaging और recipient-oriented tools के लिए dedicated capabilities रखी गई हैं.
क्या scheduling available है?
हाँ, scheduling को messaging और campaign workflows में organize किया जा सकता है. Actual limits deployment पर निर्भर करेंगी.
क्या group messaging supported है?
हाँ, group discovery, member-oriented workflows और group messaging के लिए dedicated product capabilities हैं.
API documentation कहाँ मिलेगी?
Public API documentation में currently documented message और group examples उपलब्ध हैं.
Support कैसे मिलेगा?
Business enquiry और setup discussion के लिए Contact page से request भेजें.
