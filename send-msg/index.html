How to Use

Follow these steps to send your message.

01

Select WhatsApp Account

Choose the connected number from which the message should be sent.

02

Choose Sending Mode

Select Send Now for immediate delivery or Schedule Message for a future time.

03

Add Recipients

Enter one or multiple numbers separated by commas, or upload an Excel list.

04

Write Your Message

Type your content, use the Emoji button, and add an attachment when required.

05

Remove Duplicates

Use the duplicate remover before sending large lists to keep recipient data clean.

06

Send or Schedule

Click Send Message. Scheduled messages will be queued for the selected date and time.
